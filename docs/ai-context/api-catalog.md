## Related business flows

- Many write operations use `POST .../process` with a composite Commands VM (create/update/delete command lists).

- Chain/workflow: `BiznessEventProcessConfiguration`, `SA_ChainMenu`, `SA_NextEvent`, `BiznessEvent_PCTrack`.
- Tender/costing: `ProcurementTender` including `getTenderCosting` / `processTenderCosting`.
- Third-party: `GlobalAPIController` GUID-obfuscated routes.
