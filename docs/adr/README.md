# Architecture Decision Records (ADRs)

Use this folder for **lasting** architectural or product-behavior decisions that outlive a single task.

- One decision per file: `NNNN-short-title.md` (e.g. `0001-frontend-only-default.md`).
- Link the ADR from the relevant `docs/ai-work/history/TASK-*.md`.
- If a later decision supersedes an older one: add a new ADR; mark the old one **Superseded** with a link — do not silently rewrite history.

**Do not** put routine task progress here — that belongs in `docs/ai-work/`.  
**Do not** duplicate Graphify or full architecture docs here — link them.

No product ADRs yet. Create the first when a decision needs permanent record beyond task history.
